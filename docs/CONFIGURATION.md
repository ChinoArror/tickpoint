# TickPoint Configuration

This document lists every configuration value the Worker reads (from `src/server/env.ts`), where each one comes from, and how local development differs from production.

Values in this document are placeholders. Never commit real values.

## Where configuration lives

| Source | Used for | Committed? |
| --- | --- | --- |
| `wrangler.jsonc` `vars` | Non-secret values in production | Yes (no secrets) |
| Worker secrets (`wrangler secret put`, or `node scripts/sync-secrets.mjs --remote`) | Secret values in production | No (stored by Cloudflare) |
| `.dev.vars` (generated by `node scripts/sync-secrets.mjs --local`) | Local values for `npm run dev` and `wrangler dev` | No (git-ignored) |
| `.design/secret.json` | Input for the sync script | No (git-ignored) |
| `.design/vapid.json` | VAPID key pair, generated once by the sync script | No (git-ignored) |
| `.dev.vars.example` | Template with placeholders | Yes |

`.dev.vars` values take precedence over `wrangler.jsonc` `vars` during local development.

## Bindings

| Name | Type | Required | Configured in | Purpose |
| --- | --- | --- | --- | --- |
| `DB` | binding (D1) | Yes | `d1_databases` in `wrangler.jsonc` (database `tickpoint-db`) | All application data |
| `FILES` | binding (R2) | Yes for backups and attachments | `r2_buckets` in `wrangler.jsonc` (bucket `tickpoint-save`) | JSON backups and file attachments |
| `ASSETS` | binding (static assets) | Yes | `assets` in `wrangler.jsonc` | Serves the Vue SPA |
| `EMAIL` | binding (`send_email`) | When `EMAIL_PROVIDER` is `cloudflare` | `"send_email": [{ "name": "EMAIL" }]` in `wrangler.jsonc` | Cloudflare Email Service sender (domain `point.aryuki.com` onboarded) |

## Variables and secrets

| Name | Type | Required | Default or example | Purpose |
| --- | --- | --- | --- | --- |
| `APP_ENV` | var | Yes | production: `production`; local: `development` | Environment mode. `development` plus `DEV_AUTH_BYPASS` enables the local sign-in. Allowed values: `production`, `development`, `test`. |
| `APP_ORIGIN` | var | Yes | production: `https://point.aryuki.com`; local: `http://localhost:5173` | Public origin. Used to build absolute links in notifications and to check the origin. |
| `AUTH_BASE_URL` | var | Yes | `https://accounts.aryuki.com` | AuthCenter base URL (sign-in, verify, quota, analytics). |
| `AUTH_APP_ID` | var | Yes | `tickpoint` (set from `app-id`) | AuthCenter app id, sent with every AuthCenter call. |
| `AUTH_CALLBACK_URL` | var | Yes | `https://point.aryuki.com/sso-callback` (set from `callback-url`) | Callback URL. Must match the AuthCenter app registration exactly. |
| `AUTH_APP_SECRET` | secret | Yes | `<from secret.json app-secret>` | Authenticates TickPoint to AuthCenter quota, usage and analytics calls. It is **not** the JWT signing key. It also derives the AES-GCM key that encrypts stored JWTs. |
| `GEMINI_API_KEY` | secret | No (AI disabled without it) | `<from secret.json GeminiApiKey>` | Google Gemini API key. |
| `GEMINI_MODEL` | var | Yes for AI | `gemini-3.8-flash` (set from `GeminiModel`) | Gemini model id. |
| `VAPID_PUBLIC_KEY` | var | No (push disabled without it) | `<generated by sync script>` | Public VAPID key, sent to the browser for Web Push subscriptions. |
| `VAPID_PRIVATE_KEY` | secret | No (push disabled without it) | `<generated by sync script>` | Private VAPID key for signing push requests. |
| `VAPID_SUBJECT` | var | Yes for push | `mailto:<contact address>` | Contact URI sent to push services. |
| `EMAIL_PROVIDER` | var | Yes | `cloudflare` | `none`, `resend` or `cloudflare`. `none` means email is skipped. |
| `EMAIL_FROM` | var | Yes | `TickPoint <noreply@point.aryuki.com>` | Sender name and address for all notification email. |
| `RESEND_API_KEY` | secret | Only when `EMAIL_PROVIDER` is `resend` | `<resend api key>` | Resend API key. |
| `DEV_AUTH_BYPASS` | var | No | `true` (local only) | Enables the Alice and Bob development sign-in. Ignored unless `APP_ENV` is `development` and the request host is `localhost`, `127.0.0.1` or `[::1]`. Never set in production. |

## Mapping from `.design/secret.json`

`scripts/sync-secrets.mjs` reads `.design/secret.json` (never committed) and maps its keys as follows. The script never prints values.

| secret.json key | Application setting | Kind | Notes |
| --- | --- | --- | --- |
| `app-id` | `AUTH_APP_ID` | var | Written into `wrangler.jsonc`. |
| `app-secret` | `AUTH_APP_SECRET` | secret | Written to `.dev.vars` (local) or uploaded with `wrangler secret put` (remote). |
| `callback-url` | `AUTH_CALLBACK_URL` | var | Written into `wrangler.jsonc`. |
| `workers-name` | Worker name (`name` in `wrangler.jsonc`) | non-secret | Listed in the script header, but the current script does **not** write it. Edit `wrangler.jsonc` by hand if it changes. |
| `d1-id` | `d1_databases[].database_id` | non-secret | Listed in the script header, but not written by the current script. Edit `wrangler.jsonc` by hand. |
| `d1-name` | `d1_databases[].database_name` | non-secret | Listed in the script header, but not written by the current script. Edit `wrangler.jsonc` by hand. |
| `r2-name` | `r2_buckets[].bucket_name` | non-secret | Listed in the script header, but not written by the current script. Edit `wrangler.jsonc` by hand. |
| `GeminiApiKey` | `GEMINI_API_KEY` | secret | Written to `.dev.vars` or uploaded as a secret. |
| `GeminiModel` | `GEMINI_MODEL` | var | Written into `wrangler.jsonc`. |

The VAPID pair is not in `secret.json`. The script generates it once into `.design/vapid.json` and then writes `VAPID_PUBLIC_KEY` (var) and `VAPID_PRIVATE_KEY` (secret).

Note: the script rewrites `wrangler.jsonc` on every run, so check the diff after running it.

## Local versus production

| Setting | Production (`wrangler.jsonc` and secrets) | Local (`.dev.vars`) |
| --- | --- | --- |
| `APP_ENV` | `production` | `development` |
| `APP_ORIGIN` | `https://point.aryuki.com` | `http://localhost:5173` |
| `DEV_AUTH_BYPASS` | not set | `true` |
| `AUTH_CALLBACK_URL` | `https://point.aryuki.com/sso-callback` | Not used for sign-in (AuthCenter cannot redirect to localhost) |
| Sign-in | AuthCenter (`/api/v1/auth/login` redirect) | Alice or Bob development sign-in |
| Secrets | Worker secret store | `.dev.vars` |
| Cron | Runs every minute | Run manually (see README troubleshooting) |

## Example `.dev.vars` keys

The file is generated by `node scripts/sync-secrets.mjs --local`. Its keys are:

```text
APP_ENV=development
APP_ORIGIN=http://localhost:5173
DEV_AUTH_BYPASS=true
VAPID_PUBLIC_KEY=<generated>
AUTH_APP_SECRET=<from secret.json app-secret>
GEMINI_API_KEY=<from secret.json GeminiApiKey>
VAPID_PRIVATE_KEY=<generated>
```

A placeholder template is in `.dev.vars.example`.
