# TickPoint Android app

The Android app is a Capacitor 8 shell around the same Vue app that runs in the browser. The compiled
web bundle is packaged inside the APK. API calls go to `https://point.aryuki.com/api/v1` using a bearer
token. Architecture and contracts: [`ARCHITECTURE.md`](ARCHITECTURE.md). Also see
[`ANDROID_AUTH.md`](ANDROID_AUTH.md), [`ANDROID_NOTIFICATIONS.md`](ANDROID_NOTIFICATIONS.md) and
[`ANDROID_SIGNING.md`](ANDROID_SIGNING.md).

| Item | Value |
|---|---|
| Application ID | `com.aryuki.tickpoint` |
| Name | TickPoint |
| Version | `1.0.0` (versionCode `1`) |
| minSdk / targetSdk / compileSdk | 24 / 36 / 36 |
| Permissions | `INTERNET`, `POST_NOTIFICATIONS`, plus `ACCESS_NETWORK_STATE` and `WAKE_LOCK` declared by the Firebase Messaging libraries (needed for FCM; see below) |

## Prerequisites

| Tool | Version used | Notes |
|---|---|---|
| Node.js | 24.x | Root project and `android-app` |
| JDK | 21 (Eclipse Adoptium) | `JAVA_HOME`, for Gradle and `jarsigner` |
| Android SDK | platform `android-36`, build-tools `36.0.0` | `ANDROID_HOME` (or `ANDROID_SDK_ROOT`) |
| Gradle | 8.14.3 (wrapper) | `android/gradlew.bat` |
| Android Gradle Plugin | 8.13.0 | from the Capacitor template |
| Emulator (optional) | system image `google_apis_playstore;x86_64` android-36 | WHPX on Windows |

Defaults used by the scripts if the variables are unset: `JAVA_HOME=D:/CTools/android/jdk-21` and
`ANDROID_HOME=D:/CTools/android/sdk`. Set your own paths when they differ.

`android/local.properties` holds `sdk.dir`. It is git-ignored. Write it with forward slashes, for example
`sdk.dir=D:/CTools/android/sdk`. Backslashes must be escaped as Java properties require, and a single
backslash silently breaks the path.

## Commands

Run from `android-app/` (`npm install` once):

| Command | What it does |
|---|---|
| `npm install` | Installs the Capacitor packages into `android-app/node_modules` |
| `npm run build:web` | Builds the root Vue app into `android-app/www` (with the Android alias for the native module) |
| `npm run sync` | `build:web`, then `npx cap sync android` (copies `www` into the Android project) |
| `npm run typecheck` | Type-checks `src/native` (against the root client types) |
| `npm run generate:assets` | Re-renders the legacy launcher PNGs and splash PNGs (Playwright, Edge) |
| `npm run release` | Sync, `clean assembleRelease bundleRelease`, copies to `artifacts/`, verifies, writes `SHA256SUMS.txt` and `BUILD_INFO.md` |
| `npm run verify` | Re-checks the artifacts (apksigner, aapt2, keytool for the AAB signer, checksums) |
| `node scripts/release.mjs --skip-build` | Re-copies the last Gradle outputs, verifies, and rewrites `SHA256SUMS.txt` and `BUILD_INFO.md` without rebuilding |
| `node scripts/emulator-test.mjs` | Creates the AVD if needed, boots it headless, installs and launches the release APK, saves a screenshot to `test-output/` |

A release build needs the signing properties file (see `ANDROID_SIGNING.md`). It fails loudly without one.

For a debug build for development, `cd android && gradlew.bat assembleDebug` (after `npm run sync`).
Debug builds are not release artifacts.

```text
    storage.ts             Preferences (non-secret) and SecureStore (token)
    plugins.ts             registerPlugin for the two native helpers
    util.ts, hooks.ts      Validators, encoders, router/session hooks
    pwa-register-stub.ts  Inert stub for the PWA virtual module (no service worker in the APK)
  scripts/

    verify.mjs            Artifact verification (apksigner, aapt2, jarsigner)
    generate-android-assets.mjs  Legacy PNG and splash assets
    emulator-test.mjs     Emulator helper
    lib/android.mjs       Shared tool paths and parsers
  android/                 Native Android project (generated by cap add, then customised)
    app/src/main/java/com/aryuki/tickpoint/
      MainActivity.java     Registers the two plugins
      SecureStorePlugin.java  AES-256-GCM in the Android Keystore
      AppSettingsPlugin.java  Notification settings intent and push support check
    app/src/main/AndroidManifest.xml
    app/build.gradle        Versions, release signing, R8 and shrinking
    app/proguard-rules.pro
    app/src/main/res/       Icons (vector and PNG), splash, styles, network security config
  artifacts/               Release outputs (tracked in Git): APK, AAB, checksums, build info
  test-output/             Local screenshots and logs (ignored)
  docs/                    This documentation
```

The web bundle written to `www/` is ignored by Git and regenerated by `npm run sync`.

## Troubleshooting

- **`SDK location not found` or `Failed to find Build Tools revision 35.0.0`:** fix `android/local.properties`
  (see above) and make sure `buildToolsVersion` is `36.0.0` (set in `android/app/build.gradle` and for all
  subprojects in `android/build.gradle`).
- **Resource merge error "--" in a comment:** XML comments cannot contain `--`. Check `res/values/*.xml`.
- **`'gradlew.bat' is not recognized`** when running from Node: the script passes the full path, because
  `cmd` does not search the working directory when `NoDefaultCurrentDirectoryInExePath` is set.
- **Gradle appears stuck:** causes seen on this host: (1) a dependency download stalled with no socket timeout,
  now bounded by `systemProp.http.socketTimeout` in `android/gradle.properties`; (2) a killed client left the
  daemon waiting (run `android\gradlew.bat --stop`, or stop `java.exe`, and remove stale busy entries in
  `%USERPROFILE%\.gradle\daemon\8.14.3\registry.bin`); (3) Kotlin compile daemon stalls, avoided with
  `kotlin.compiler.execution.strategy=in-process`. A cold release build took roughly 20 minutes here.
- **`cap sync` regenerates `res/xml/config.xml` with `<access origin="*" />`:** this is Cordova legacy. Capacitor
  decides navigation from `capacitor.config.ts` (`Bridge.launchIntent`), so remote pages do not load in the WebView.
  The line is kept as generated; do not rely on it for security.
- **Release build says the signing file is missing:** the message is intentional. Create the properties file or
  set `TICKPOINT_SIGNING_PROPS`. Release builds never fall back to debug signing.
- **Blank screen in the app:** check `adb logcat -s Capacitor,chromium` and confirm `www/index.html` exists
  (run `npm run sync`).
- **Bottom navigation under the gesture bar:** the web layout uses `env(safe-area-inset-bottom)`. Check on the
  device or emulator that the edge-to-edge insets are applied.
- **Push always "Unavailable":** expected without `google-services.json` (see `ANDROID_NOTIFICATIONS.md`).
- **Sign-in custom tab opens but nothing returns:** check the App Link verification (`ANDROID_AUTH.md`).
